# 📂 Proyecto Final – Curso de Git & GitHub (Gen 1)

Este repositorio contiene el proyecto final del curso de **Git / GitHub - Generación 1**, donde se aplican los conocimientos adquiridos sobre control de versiones, ramas, commits, pull requests y colaboración en GitHub.

## 📁 Estructura del Proyecto

El proyecto está conformado por los siguientes archivos Markdown:

- `Informacion.md`: Información personal del autor.
- `Proyectos.md`: Proyectos desarrollados previamente.
- `Clasificacion.md`: Clasificación personal (ej. libros, música, videojuegos).
- `README.md`: Este archivo, que describe y documenta el repositorio.

Cada archivo se desarrolló en una rama distinta

## 🔧 Especificaciones cumplidas

✔️ Creación de 4 ramas (incluyendo master).  
✔️ Mínimo 6 commits por cada rama.  
✔️ Cambios realizados en `Proyectos.md` y `Clasificacion.md` dentro de `main`.  
✔️ Fusión de ramas hacia la rama principal.  
✔️ Repositorio subido a GitHub con historial completo.  
✔️ Fork de al menos 5 repositorios de compañeros.  
✔️ Pull requests con modificaciones a `Clasificacion.md`.
